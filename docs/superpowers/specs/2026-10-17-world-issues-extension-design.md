# 오늘의 세계 이슈판 4단계 설계: 크롬 확장

작성일: 2026-10-17 · 앞 문서: 1~3단계 설계(`2026-10-17-world-issues-*-design.md`)

## 목표

크롬 툴바에서 오늘의 나라별 상위 이슈를 바로 보고, 고른 분야·나라의 고득점 이슈가 뜨면 시스템 알림으로 받는다. 사이트(`https://gtdaily.news`) 방문을 늘리는 것이 목적이다.

성공 기준:
- 아이콘을 누르면 팝업에 나라별 상위 이슈(점수·분야·제목)가 4개 언어 중 고른 언어로 보이고, 누르면 해당 이슈 페이지가 새 탭으로 열린다.
- 한 시간마다 `https://gtdaily.news/feed.json`을 확인해, 조건(기준 점수 이상 + 고른 분야 + 고른 나라)에 맞고 아직 알리지 않은 이슈를 크롬 알림으로 띄운다. 알림을 누르면 이슈 페이지가 열린다.
- 알림은 기본 켜짐, 팝업에서 바로 끌 수 있다. 한 번에 최대 3개(넘으면 "외 N건" 한 개로 묶음), 같은 이슈는 한 번만, 선택한 방해 금지 시간에는 보내지 않는다.
- 아이콘 숫자(배지)는 조건에 맞는 새 이슈 중 아직 팝업에서 보지 않은 수. 팝업을 열면 0.
- 권한은 `alarms`, `notifications`, `storage`, 호스트 `https://gtdaily.news/*`만.
- 웹스토어에 올릴 zip, 4개 언어 소개 문구, 스크린샷, 개인정보 안내가 준비된다(등록·결제는 사용자).

하지 않는 것: 새 탭 바꾸기(설정으로 켜고 끌 수 없어 거부감·심사 부담이 큼 → 팝업의 "전체 보기"로 대신), 로그인·계정, 방문 기록 읽기, 다른 사이트 접근, 분석 도구.

## 1. 구성

```
extension/
  manifest.json        MV3, default_locale "en", 이름·설명은 _locales
  _locales/{en,ko,ja,zh_CN}/messages.json
  lib/core.js          순수 함수(언어 고르기, 알릴 이슈 고르기, 방해 금지 시간 판정, 배지 수) — node --test로 테스트
  background.js        서비스 워커: 설치 시 기본 설정, alarms(60분) → feed.json 확인 → 알림·배지
  popup.html/.js/.css  나라 탭, 상위 이슈 목록, 알림 스위치, "전체 보기", 설정 열기
  board.html           "전체 보기": 5개 나라 상위 이슈를 한 화면에(팝업과 같은 코드, 넓은 배치)
  options.html/.js     언어, 알림 켜기, 기준 점수(7.5~9.5, 0.5 간격), 분야 4개·나라 5개 체크, 방해 금지(없음/23~07시/22~08시)
  icons/16,32,48,128.png
  test/core.test.mjs
store/                 웹스토어 소개 문구(4개 언어), 스크린샷 1280x800, 개인정보 안내
```

빌드 단계 없음. `zip -r gtdaily-extension.zip extension -x 'extension/test/*'`로 묶는다.

## 2. 데이터

- `feed.json`(이미 있음): `updated`, 나라별 상위 5개 `{id, field, score, title{4개 언어}, url{4개 언어}}`.
- 알림 후보를 넉넉히 보려고 `feed.json`을 나라별 상위 10개로 늘린다(`gen/feeds.py` `feed_json`, 테스트 수정).
- 저장(`chrome.storage.local`): `settings`(언어·알림·점수·분야·나라·방해 금지), `notified`(알린 id 목록, 최근 300개), `seenUpdated`(팝업에서 마지막으로 본 `updated`), `badgeIds`.
- 팝업은 열 때마다 `feed.json`을 새로 받고, 실패하면 마지막으로 받은 내용(`cache`)을 보여 준다.

## 3. 알림 규칙 (`core.pickAlerts(feed, settings, notified)`)

1. `settings.notify`가 꺼져 있으면 없음.
2. 모든 나라 이슈 중 `score >= settings.minScore`, `field ∈ settings.fields`, 나라 ∈ `settings.countries`, `id ∉ notified`.
3. 점수 높은 순. 3개 이하면 각각 알림, 4개 이상이면 상위 2개 + "외 N건" 1개.
4. 방해 금지 시간이면 보내지 않되 `notified`에 넣지 않는다(끝난 뒤 다음 확인 때 보냄).
- 기본값: 알림 켜짐, 8.5점, 분야·나라 전부, 방해 금지 없음, 언어는 브라우저 언어(ko/ja/zh로 시작하면 그 언어, 아니면 en).
- 설치 직후 옵션 페이지를 한 번 열어 "알림 받을 분야를 골라 주세요"를 보여 준다.

## 4. 화면

- 사이트와 같은 디자인 토큰(밝은/어두운 모드)과 나라 색을 쓴다. 팝업 폭 380px.
- 팝업 위: 사이트 이름, 갱신 시각(내 시간), 알림 스위치, 설정(⚙). 아래: 나라 탭 5개, 이슈 목록(점수 원, 분야 색 점, 제목), 맨 아래 "전체 보기"·"사이트 열기".
- 모든 링크는 `chrome.tabs.create`로 새 탭.

## 5. 웹스토어 준비

- 소개 문구(짧은 설명 132자 이하, 긴 설명) 4개 언어, 스크린샷 3장(팝업·전체 보기·알림), 아이콘 128.
- 개인정보: 수집하는 사용자 데이터 없음, 설정은 기기 안 `chrome.storage.local`에만, 외부 전송은 `gtdaily.news/feed.json` 요청뿐. 사이트 개인정보처리방침에 확장 단락을 4개 언어로 추가한다.
- 권한 설명(심사용): alarms(한 시간마다 확인), notifications(이슈 알림), storage(설정 저장), gtdaily.news(이슈 목록 받기).
- 사용자 할 일: 크롬 웹스토어 개발자 등록($5 1회), zip 업로드, 소개 문구·스크린샷 붙여 넣기, 제출.

## 6. 테스트

- `node --test extension/test/`: 언어 고르기, `pickAlerts`(점수·분야·나라·이미 알림·끔·3개 초과 묶음·방해 금지 경계 23:00/06:59/07:00), 배지 수.
- `tests/test_feeds.py`: `feed.json` 나라별 최대 10개.
- 수동: 크롬 "압축해제된 확장 프로그램 로드"로 설치해 팝업·알림·설정을 직접 확인(사용자 맥에서).
